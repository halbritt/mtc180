Trace format

Import a JSON file with a samples array ordered by time in seconds. Coordinates are metres: x downrange, y crossrange and z altitude. Start at release, mark each ground strike with "event": "contact", and end with "event": "rest". An optional target point enables error measurements. Optional design and setting strings identify the configuration used for a trial.
